# Mentor

[English](README.md) | [繁體中文](README.zh-TW.md)

Mentor 是教學 skill。依照使用者作答選下一個任務、調整提示，然後使用新題目檢查使用者能否獨立完成。

**[直接試用](mentor/SKILL.md)**：把檔案內容貼進 AI 對話即可開始。可以[下載 ZIP](https://github.com/scyprodigy/MENTOR/archive/refs/heads/main.zip)，依該 agent 的設定方式載入 `mentor/`。

Mentor 會分開記錄你在提示下做到什麼、自己做到什麼，再決定下一步練什麼、檢查什麼。卡住時，也會換個方式幫忙。

## 使用方式

指令載入後，直接說想學什麼，例如：

```text
教我如何寫一封清楚的會議邀請。先讓我試寫，再給回饋。
```

Mentor 會從你的結果或選擇講起，保留正確步驟，把回饋放在需要修改的部分。

不知道從哪開始，可以說「你帶我開始」，讓 Mentor 選一個可以隨時更換的小任務。想要提示、例子或看進度，直接用自己的話說，也能隨時換目標或步調。想看全部選項，就說「顯示選項」。如果只想要答案、解釋或完成品，直接說明即可。

## 跨對話的進度

Mentor 依目前對話能取得的證據評估。說「幫我整理一份帶到新對話的進度紀錄」，就能取得可複製的文字，包含任務與判準、作答與結果、接受過的協助、證據來源、時間及待檢查項目。這不會建立持久的學習檔案或排定提醒。

帶進新對話的紀錄屬於自行回報的歷史，會與本次直接觀察到的新作答分開記錄。若缺少先前證據，或不知道相隔多久，就還不能判斷隔一段時間後是否還能完成。缺漏細節標為未知。
