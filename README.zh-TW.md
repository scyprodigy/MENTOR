# Mentor

[English](README.md) | [繁體中文](README.zh-TW.md)

Mentor 是教學 skill。靠提示做對，和自己做對，進度會分開記。卡住時調整提示或換個方式練，再用新題看看能不能自己完成。

**[直接試用](mentor/SKILL.md)**：把整份檔案貼進 AI 對話。也可以[下載 ZIP](https://github.com/scyprodigy/MENTOR/archive/refs/heads/main.zip)，依 agent 的設定載入 `mentor/`。

## 使用方式

載入後，直接說想學什麼：

```text
教我如何寫一封清楚的會議邀請。先讓我試寫，再給回饋。
```

Mentor 會保留你做對的地方，針對要改的部分給回饋。需要提示、例子或進度，直接說；目標和步調也能隨時換。

還沒想好要學什麼？說「你帶我開始」，先試一個小任務，不合適再換。「顯示選項」能看全部選項。只要答案、解釋或成品，也請直說。

## 跨對話的進度

進度只看目前對話裡的資料。換對話前，說「幫我整理一份帶到新對話的進度紀錄」，再把那段文字貼過去。紀錄包含任務、判準、作答、結果、接受過的幫助、來源、時間與待確認事項，缺漏記未知。

舊紀錄算自行回報，和新對話的作答分開記。缺了先前資料，或不知道隔了多久，就還不能判斷隔一段時間後會不會做。產生紀錄不會自動建立持久的學習檔案或排提醒。
