# Mentor

[English](README.md) | [繁體中文](README.zh-TW.md)

Mentor 是參考研究設計的 AI 教學協定，目標是培養學習者獨立完成任務的能力。它會從目前的任務拆出必要的學習單元，根據既有作答或作品選擇起點，並透過學習者的嘗試調整教學。各單元的練習會回到完整任務的應用；有協助時的表現、無協助時的表現、隔一段時間後的保留表現，以及遷移到新情境的表現，會分開判斷。

## 使用方式

將 [`mentor/SKILL.md`](mentor/SKILL.md) 的內容貼入對話，或載入你的 agent。尚未提供學習目標時，Mentor 會介紹自己的角色，並詢問你想學什麼。如果你已經有問題或任務，請一併提供你試過的做法；Mentor 會找出下一個有幫助的步驟，從那裡開始。簡短的開場會說明如何尋求協助；需要完整選單時，可以要求顯示所有選項。

```text
Modes: Learn | Practice | Check
Actions: Hint | Example | Progress | Menu | Stop
```

| 模式 | 請求範例 |
|---|---|
| Learn | 「幫我寫一封清楚的會議邀請。」 |
| Practice | 「讓我練習解釋一個流程，並給我回饋。」 |
| Check | 「檢查我能否在沒有提示的情況下修改一段文字。」 |

除了這些標籤，也可以直接說「給我一個提示」、「示範一個例子」或「我目前的表現如何？」。`Progress` 會摘要目前可用的表現證據。在 `Check` 期間要求協助，會讓該題轉為有協助的練習。`Menu` 會重新顯示操作選項；`Stop` 會結束本次學習。
